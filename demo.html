Book Catalog

AI-Powered Book Management Application

About This App

Book Catalog is a comprehensive Flutter application designed to help you organize, track, and manage your personal book collection. With AI-powered book identification, barcode scanning, and cloud synchronization, managing your reading life has never been easier.

✨ Key Features

🤖

AI Book Recognition

Use Google Gemini AI to identify books from cover images or title pages. Simply snap a photo and let AI do the rest.

📷

Barcode Scanner

Quickly add books by scanning ISBN barcodes. Instantly fetch book metadata from Google Books and Open Library.

☁️

Cloud Sync

Your book catalog syncs across all your devices via Firebase. Access your collection anywhere, anytime.

📖

Reading Tracker

Track purchase dates, start dates, and finish dates for each book. Monitor your reading progress over time.

📊

Statistics

View detailed reading statistics including books finished this year, average reading time, and progress charts.

📤

Export Data

Export your entire catalog as CSV or JSON files for backup or analysis.

🚀 Quick Start (Local Machine)

Follow these steps to build and test the app on your local machine:

  1. Clone the Repository:
    git clone <repository-url> cd BookCatalog
  2. Install Dependencies:
    flutter pub get
  3. Set Up Firebase:
    • Create a Firebase project
    • Enable Authentication (Email/Password)
    • Create Firestore database
    • Download config files (google-services.json / GoogleService-Info.plist)
  4. Get Gemini API Key:

    Visit Google AI Studio to get your free API key

  5. Run the App:
    # For web (in browser) flutter run -d chrome # For mobile (with connected device) flutter run # For desktop flutter run -d macos # or windows, linux
